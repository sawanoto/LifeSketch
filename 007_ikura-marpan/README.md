# LifeSketch 007 · イクラマーパン

軍艦巻きそのものが三つ目のマーパン。イクラに触れると90msの膜の変形から破裂し、金色の旨味と柔らかい低音が約2秒広がります。25粒は独立し、全粒がなくなると1.5秒後に補充が始まります。スコアや制限時間はありません。

リポジトリルートで `python -m http.server 8000` を実行し、`/007_ikura-marpan/` を開きます。共通の `shared/marpan-25d.js` の `drawEyes` と同梱のp5.js / p5.soundを使用。外部画像・音源・CDNへの依存はありません。

- マウスクリック／タップで一粒ずつ。複数の指で同時に操作可能。
- キャンバスにフォーカスしてEnterまたはSpaceでも一粒ずつ操作できます。
- 最初の操作で `userStartAudio()`。Web Audio APIの高域の短い音と低域の余韻を合成。最大12音、マスターゲイン、コンプレッサーで音の重なりを制御します。「音 オフ」で既存の余韻も消音。
- 「絵本のための PNG 保存」を開くと、全粒／破裂直後／大きな波紋の3場面を2400 × 3000 PNGとして保存できます。UIは含まれず、遊んでいる状態も変わりません。
- 内部座標を保ったまま画面サイズへ拡縮。pixelDensityは最大2。波紋の寿命と音声ノードを管理し、連続操作で蓄積しません。

自動ブラウザー検証：デスクトップ1280×1000、タッチ390×844で一粒操作、初回音声起動、全粒破裂後の補充、3種類のPNG、ギャラリー登録。最終的な音色と音量は実機でも確認してください。
