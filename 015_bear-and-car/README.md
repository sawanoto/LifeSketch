# LifeSketch 015 · クマと車

「怖いもの」と「危険なもの」は、同じだろうか。

開始で左右が同時に動きます。車・クマは同じ3秒周期、同じ方向・速度で通過。車は開始3秒後から毎回、クマは開始5,067秒後から1,689回の通過ごとに倒れます。共通 `../shared/marpan-25d.js` をそのまま参照し、全体の回転で転倒・復帰します。転倒180ms、静止770ms、復帰400ms。乱数・フレーム数で被害を決めません。

## 統計（2026-10-21確認）

比較対象は **2023年1〜12月**。企画概算の360人・52万人・1,500倍を、確認した同じ暦年の値で更新しています。最新年を示すものではありません。

- [警察庁・令和6年版犯罪被害者白書 資料12](https://www.npa.go.jp/hanzaihigai/whitepaper/2024/zenbun/part3_siryo/siryo-12.html)：2023年死者2,678人（24時間以内）＋負傷者365,595人＝368,273人。車の絵は道路交通事故全体の代理表現で、自動車との衝突だけに限定した人数ではありません。
- [環境省・令和4年度月別人身被害表](https://www.env.go.jp/nature/choju/effort/effort12/r04injury-qe.pdf)：2023年1〜3月の被害者数は0、1、0人。
- [環境省・令和5年度月別人身被害表](https://www.env.go.jp/nature/choju/effort/effort12/r05injury-qe.pdf)：2023年4〜12月は5、17、17、17、15、38、73、30、5人。合計217人。前項と合算し暦年218人。被害者数には死亡者が含まれるため死亡者は加算しません。年度合計219人と暦年合計218人を区別します。
- [総務省統計局・2023年10月1日人口推計](https://www.stat.go.jp/data/jinsui/2023np/index.html)：全国総人口124,352,000人。

年間リスクの概算＝被害者数÷総人口。その逆数は交通337.6626人、クマ570,422.0183人。表示は約338人に1人・約57万人に1人。比率は368,273÷218＝1,689.3257。通過への同期のため1,689に丸め、3秒×1,689＝5,067秒＝84分27秒をクマの被害間隔とします。丸め誤差は約0.02%。数値と資料リンクは「確率を見る」で確認できます。

全国人口当たりの年間死傷リスクを比較した表現です。車やクマとの遭遇1回当たりの危険度を示すものではありません。地域・活動・接触頻度・重症度や個人差を表さず、クマの安全を主張するものではありません。

## 実装・確認

外部CDNに依存せず既存のローカルp5.jsを利用。GitHub Pagesのサブディレクトリに対応する相対パス。作品一覧は `works.js`。スマートフォンでも左右を維持し、パネルごとにクリップします。

`performance.now()` の差分で再生中の表示時間を積算。非表示時はループを止め、復帰時に時計の基準を再設定します。経過時間から現在の状態を直接計算するため、遅いフレームの後も過去の被害を連続再生しません。リセットで時計・開始・統計表示を初期化。

PNGボタンは現在の時刻の場面を3200×2400pxで再描画し、題名・左右のラベル・問いを加えて保存します。書き出し後は元の解像度へ戻します。

リポジトリルートを `python -m http.server 8000` で配信して `/015_bear-and-car/` とギャラリーを確認。周期・長時間・非表示・リセットの検証：`node --test 015_bear-and-car/timing.test.cjs`。
