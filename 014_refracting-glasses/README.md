# LifeSketch 014 · 屈折する眼鏡

眼鏡を上下に動かし、同じ姿の3本の木へ視線を向ける静かな作品。上から「期待」「現実」「不安」。どの方向にも評価や特別な演出を付けません。音はありません。

- 凸レンズをマウスまたは指で上下にドラッグ。横位置は固定し、離した場所を保持します。
- 上端で期待、中央で現実、下端で不安へ点線が届きます。途中も連続的に方向が変わります。
- Tabで眼鏡を選び、上下矢印で移動。Homeで上端、Endで下端、0で中央。
- 画面サイズを変えても相対的な眼鏡の位置を維持します。

共通 `../shared/marpan-25d.js` と既存のローカルp5.jsを再利用。三つ目を維持し、瞳のみレンズを追います。木は同一の描画関数を位置とラベルだけ変えて描きます。屈折は物理シミュレーションではなく、指定された操作関係を優先した2区間の点線です。Pointer Eventsとpointer captureでタッチ・マウスに対応し、描画は操作・リサイズ時のみ更新します。

ビルド不要。リポジトリルートをHTTP配信し、一覧の014、または `014_refracting-glasses/` を開きます。
