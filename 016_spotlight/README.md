# LifeSketch 016 · スポットライト / Spotlight

暗闇の中で、光を動かす作品。左は笑顔、中央は通常の表情、右は泣いた表情。同じ色・大きさ・向きの3体を横一列に置き、初期の光は中央に置きます。画面に思想の説明や結論は表示しません。音はありません。

## 実装

既存のローカルp5.jsと共通 `../shared/marpan-25d.js` を参照。共通描画は変更せず、既存の `happy`・`pupil`・`crying` を使用。右の目元に静止した涙を加えます。自動まばたき・視線追従・表情変化はありません。

単一の放射状グラデーションで暗幕を描画し、中心から外側へ自然に減光。光の直径は体幅の1.52倍。3体の間隔と光の大きさを画面に合わせて調整し、3体同時には明るくできません。暗幕の外もごくわずかに姿を残します。

マウス移動、タップ・指のドラッグで自由に移動。時間差分に基づく補間で滑らかに追従し、手を離してもその場所に留まります。主ポインターのみを使用し、指の追加で飛びません。Pointer Captureでドラッグを継続し、CSSのtouch-actionでスクロールを防止。Tabでキャンバスにフォーカスし、矢印キーでも操作可能です。画面回転・リサイズでは光の相対位置を維持します。

## 確認

リポジトリルートをHTTP配信し、Chromium / Playwrightで検証。

- PC 1440×900：初期中央、マウス移動、表情固定、900×650への変更、ギャラリー登録。
- スマートフォン相当390×844：タップ・タッチドラッグ、スクロール抑止、844×390への回転、ギャラリー登録。
- ブラウザーのJavaScriptエラーなし。PC・縦長画面の描画を目視確認。
- 実機スマートフォン・Safariは未確認。
