# LifeSketch 013 · 怒りの伝染

中央の小さな炎に触れ、広がっていく煙を眺める。説明や特別な装飾を置かず、最後に穏やかなまま残る2体を周囲との対比で見せます。前作 `011_anger-flame/` とは独立した作品です。

- 中央のマーパンをタップ、クリック、またはTabで選んでEnter/Spaceで開始。開始前は中央の小さな炎だけが揺れ、煙や伝染はありません。
- 上下左右の4近傍へ、着火後0.52〜0.70秒待って煙を送り、0.78〜1.06秒かけて隣へ到達。顔色と共通の怒り目は0.95秒かけて変化します。煙の経路は各セルへの最短到達経路で、一度だけ着火します。
- 2体は固定の格子座標 `(1, 1)` と `(列数−2, 行数−2)`。他と同じ外見で煙を浴びますが、着火せず、伝染の経路には入りません。リセットやリサイズでも位置を保ちます。
- 初期画面幅で7 / 13 / 19列、縦横比に応じ7〜17の奇数行を選びます。リサイズ時は同じ盤面を拡大縮小し、途中の連鎖と2体の位置を維持します。
- リセットで開始前に戻ります。音ON/OFF、キーボード、スマートフォンのタップに対応。非表示タブでは進行を休止し消音します。
- 「静止画を書き出す」から初期・途中・最後の3200×2400px PNGを個別保存。現在の盤面と同じ経路・配置を使用し、再生状態を変えません。途中は全所要時間の48%の場面です。

## 技術

共通 `../shared/marpan-25d.js` の輪郭・三つ目・怒り表情を利用。口は追加しません。共通描画を240単位から縮小し、格子の小さなマーパンでも線を細く保ちます。炎は身体内部のクリップで描画し、煙は隣接間の到達アニメーションと着火済みの頭上の煙を別に描きます。終了後も炎と煙は継続します。動きを抑えるOS設定では炎の揺らぎを緩めます。

ローカルの同一バージョンのp5.js / p5.soundを利用。既存「怒りの炎」と同様に `userStartAudio()` 後にWeb Audioのノイズをフィルタ加工し、着火音・燃焼音・炎の数に応じた低いざわめきを生成します。燃焼の同時発音は最大6、全体のゲインとコンプレッサーで音量を抑制します。動じないセルは音を発生しません。音の利用に失敗しても視覚体験は動作します。

ビルド不要。リポジトリルートをHTTPで配信し `013_anger-contagion/` を開きます。GitHub Pagesのサブディレクトリ配信に対応する相対パスです。
