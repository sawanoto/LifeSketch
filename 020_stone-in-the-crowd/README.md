# LifeSketch 020 · 石を投げれば誰かに当たる

奥まで続くマーパンの群衆。説明文・操作ボタン・人数表示・結末はありません。

## 実装

- `../shared/marpan-25d.js` の通常表情を8種類の画像に描画し、遠近に合わせて再利用します。共通描画部品は変更しません。
- 位置をずらした密集配置を奥から手前へ描画します。画面サイズ変更時に再配置します。
- CanvasのPointer Eventsでマウス・タッチを統一し、タップ後の合成クリックによる二重投擲を防ぎます。一覧リンクは投擲対象外です。
- 手前から石が620msで飛び、一体が330msで倒れて消えます。90ms後から180msで同じ位置に通常のマーパンが戻ります。周囲は反応しません。
- 同時操作は別々の一体に割り当てます。群衆の配列は削除せず、被害数を記録しません。
- 待機中は群衆全体のキャッシュを表示して描画ループを止めます。音声はありません。

## 確認

リポジトリルートをHTTPで配信し、Chromium / Playwrightで確認。

- 1440×900（マウス）・390×844（タッチエミュレーション）で各操作が石ひとつを生成。
- 石の飛行・衝突・転倒状態への遷移、アニメーション完了後の人数維持を確認。
- 完了後のCanvasが操作前とピクセル単位で一致。
- 12回連続操作後に石・転倒状態が残らないことを確認。
- デスクトップの幅変更・モバイルの横向き相当への変更、一覧への登録を確認。
- JavaScript実行エラーなし。スマートフォン実機は未確認。
