# 時間の天秤 · LifeSketch 024

皿をクリック・タップすると分銅をひとつ置きます。長押しの自動追加・音声・リセットはありません。再読み込みで初期状態になります。

ローカルp5.jsのCanvas 2Dと共通 `shared/marpan-25d.js` を使用。マーパンは瞬き・視線・姿勢を固定します。既存の共通ファイルは変更しません。

- 経過時間から角度を計算し8秒で1周。入力と物理演算から独立しています。
- 全8皿の重量を円周上の一次モーメントへ合成。隣接は同方向、反対側は逆方向に動きます。対数圧縮とtanhで均衡の高さを±52に制限し、減衰ばねを1/120秒以下のサブステップで積分します。
- 累積値はBigInt。表示は十進各桁につき最大9個の刻印入り分銅。4桁を超える非ゼロ桁は集約分銅（Σと最大桁の刻印）で表示し、内部値は保持します。交換時には旧分銅が収束します。
- 軌跡は最大24Hzで作品座標を記録し、24秒で完全に破棄。リサイズでも過去の形は作品座標に保持します。背景タブ復帰時に空白期間を線で結びません。
- 奥行き順の描画と同じ逆順でPointer Eventsのヒット判定。前後の縮尺は70〜100%。

確認: リポジトリルートをHTTP配信し、PCと縦画面でギャラリーから開いて操作してください。実機確認はPR専用プレビューを利用します。
