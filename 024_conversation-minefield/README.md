# 024 · 会話の地雷原

鍵盤をタップ・クリック、または A / I / U / E / O で母音を鳴らします。Enter / Space の鍵盤操作にも対応。右上で消音できます。

各母音は地雷2個・空中機雷2個に対応し、入力ごとにすべて同時に爆発。230msで元の位置へ復活し、演出は650msで消えます。復活待ちの連打も受け付け、複数の入力を重ねられます。無入力時は音も爆発もありません。マーパンは共通 `shared/marpan-25d.js` を使用し、瞬き・視線移動・変形などを一切行いません。

## 音

既存作品と同じローカルの p5.js 1.9.4 / 同梱p5.soundを参照。ユーザー操作で `userStartAudio()` と AudioContext.resume を実行します。`sound.js` は日本語のフォルマントを使って短い合成母音を生成し、短いノイズと下降音を重ねます。録音・音声認識・speechSynthesis・外部API・追加CDNは使いません。オリジナル合成のため録音素材のライセンスは不要です。

爆弾の数にかかわらず入力1回に母音1声と爆発音1声。ゲイン・コンプレッサー・最大32音源で音量と処理負荷を抑えます。音の明瞭さ・好み・実機の音量はPRプレビューで確認してください。

## 確認

リポジトリルートを `python -m http.server 8000` で配信し、Playwrightを利用できる環境で `node 024_conversation-minefield/tests/browser.cjs`。

ChromiumでPC（1280×900）・タッチ端末相当（390×844）、320×568・844×390・1920×1080へリサイズして検証済み。Gallery導線、全母音の正しい選別、地上・空中各2個、復活、20連打、異なる母音の重なり、無入力、マーパン不変、ユーザー操作後のAudioContext開始、全母音バッファの振幅、消音、鍵盤サイズ、横はみ出し、JS/HTTPエラーを確認。

実際のiOS Safari / Android実機のスピーカー音と聴感は未検証。自動検証は音の明瞭さを判定しません。reduced-motion時は火花と煙の移動を抑え、画面全体を点滅させません。
