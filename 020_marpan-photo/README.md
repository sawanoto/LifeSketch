# LifeSketch 020 · マーパンと記念撮影

写真を選び、マーパンを自由に追加してドラッグで配置する作品。体数の上限は設けません。タップまたは「選択中」の一覧で編集する1体を選びます。大きさ（20–250%）と角度（−180–180°）をスライダーで調整できます。矢印キーで移動、Shift併用で大きく移動。「選んだ配置を戻す」で選択中の1体を中央・元の大きさ・角度に戻します。「選んだマーパンを削除」で1体だけ削除できます。選択枠は編集画面だけに表示され、保存画像には入りません。

「カメラで撮る」でスマートフォンのカメラを起動し、撮った写真をそのまま編集できます（端末・ブラウザによっては画像選択画面になります）。「写真を選ぶ」は既存写真用です。JPEG / PNG / WebPをブラウザで読み込みます。縦横比を保って全体を表示し、画像は送信しません。読み込み失敗時には直前の写真を保持します。写真変更時には中央の1体からやり直します。

「画像を保存」で元写真と同じピクセル寸法のPNGを生成し、配置した全員を含めます。ダウンロード、完成画像の長押し保存、対応端末ではファイル共有から保存できます。操作UIは含みません。ブラウザの画像デコードに従って写真の向きを扱います。非常に大きな画像は端末のメモリやCanvas上限で保存に失敗することがあり、その場合は案内を表示します。

## 構成

- `index.html` / `style.css`: 日本語UI、モバイル対応、保存画像の表示。
- `sketch.js`: 写真の読み込み、正規化した配置状態、共通マーパン描画、合成・PNG保存を関数で分離。
- `../shared/marpan-25d.js`: 既存のマーパン。変更・複製せず利用。瞬き・アニメーション・影は追加しません。
- `../002_jomon-room/p5.min.js`: 既存ローカルp5.jsを利用。

表示用Canvasは長辺1400pxまで。保存用Canvasは写真の元解像度で生成し、マーパンも保存サイズに合わせて共通コードから再描画します。写真上のマーパンにPointer Eventsとpointer captureを使い、キャンバスだけ`touch-action: none`に設定します。キャンバス外では通常のページスクロールができます。
