# LifeSketch 024 · ゾンビ清掃婦

鳩小屋をクリックすると、鳩が飛び立ちます。空にはマーパンのアドバルーンが浮かんでいます。

## 操作・実装

- 鳩小屋をクリック・タップ（キーボードではフォーカスしてEnter/Space）すると1羽飛び立つ。音・得点・勝敗はない。
- `scene.js` は各羽の出発時に `Math.random() < 0.2` で独立抽選する。待機中の気球のみを対象とし、不在・上昇中に出発した鳩と、対象の世代が変わった鳩は通過する。
- 1羽目は表面に残る。2羽目の接触で気球・係留ロープ・刺さった鳩・接触した鳩を同じ描画フレームで消す。1.4秒後、建物の背後から6秒かけて次の気球が上昇する。
- `../shared/marpan-25d.js` を変更せず利用。p5.jsも既存のローカルファイルを参照し、外部通信・追加素材を必要としない。
- 正規化座標とResizeObserverで縦横の画面に対応。描画密度は最大2、時間刻みは最大1/120秒とし、画面外の鳩は除去する。

## 確認

リポジトリルートをHTTPで配信し、`/024_zombie-cleaner/` を開く。

```sh
node --test 024_zombie-cleaner/scene.test.cjs
```

確率境界、連続した独立抽選、1羽目の保持、2羽目での同時消失、再上昇、4周期、100羽の同時飛行、対象消失・不在・上昇中の通過を検証する。

Chromiumで1200×900と390×844の表示、クリック／タップ、消失／上昇、100羽の通過、ギャラリーからの遷移を確認。ブラウザーエラーなし。スマートフォン実機の確認はPRプレビューで行う。
