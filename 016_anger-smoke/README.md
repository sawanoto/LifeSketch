# LifeSketch 016 · 怒りの煙

左のマーパンをクリック／タップ。長押しでも怒りが増します。右は操作対象ではありません。手を離すと怒りが収まり、残った煙が遅れて薄くなり、右がゆっくり回復します。「はじめから」でリセット。「音 ON/OFF」で切り替えます。キーボードでは左のマーパンにTabで移動し、Enter／Spaceで操作できます。

共通 `../shared/marpan-25d.js` を参照し、両者の三つ目を維持。右の表情は pupil → sleepy → worried → crying のみを使います。初期の左は軽い怒り顔ですが、煙の発生量はゼロです。連続操作時は約25秒で限界状態に近づきます。最大状態から手を離すと約20秒で発生が止まり、残留煙と回復にはさらに時間がかかります。

煙は最大220粒のキャッシュした放射状グラデーションと38個の漂う雲で描画。頭から上昇し、天井で横に流れ、蓄積量に応じて層が下がります。室内でclipし、外に漏れません。前景の煙は薄くして表情を残します。消散は時間経過によるもので、排気口はありません。描画密度は最大2。reduced-motionでは震えと体の揺れを省きます。背景タブでは進行と長押しを止め、音をミュートします。

音は操作を起点にWeb Audioで生成する低音と小さな帯域制限ノイズ。外部音声素材なし。p5.js 1.9.4は既存のローカルファイルを参照し、p5.soundは同じp5.js 1.9.4配布物から同梱しています（配布物内のaddon表記は1.0.1）。音声起動に失敗しても描画・操作は継続します。

ローカル確認はリポジトリルートで `python -m http.server 8000` を実行し、`/016_anger-smoke/` を開きます。モデルの時間差・上限・30/120fpsの整合性は `node --test 016_anger-smoke/smoke.test.cjs`。
