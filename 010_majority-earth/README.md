# LifeSketch 010 · 多数決で変わる地球

`index.html` をリポジトリルートからHTTPで配信します。依存ライブラリは既存のローカルp5.js / p5.sound、キャラクターは `../shared/marpan-25d.js` を参照し、既存作品・共通描画は変更しません。

○△□ボタンで選択。0.35秒後に24体が同時に異なる形を主張します（○→□、△→○、□→△）。送信エフェクトは0.14秒だけ表示し、0.6秒後に変形を開始、約1.2秒で完了します。1.35秒後には次の選択ができます。新しい操作では前の形から0.22秒で球体へ戻ります。選択はクリック・タップ・キーボードに対応。音は最初の選択で開始し、右上で消音できます。同時投票の音量が過大にならないよう各音の音量と長さを調整しています。

球面上の頂点を立方体または三角柱の表面交点へ滑らかに補間します。大陸色は緯度経度に固定し、奥行きソートと面の照明で立体を描きます。三角形は三角柱として表現しています。

右下の「静止画を書き出す」から初期・主張中・完了を個別にPNG保存できます。各画像は3840×2160pxで描き直し、画面の拡大コピーではありません。直近の選択（未選択なら○／多数派□）を使用し、回転角は3場面共通。操作ボタンと見出しを除いた場面だけを保存します。ダウンロード後は表示サイズと進行を維持します。

実機での音量・タッチ感の最終確認はPRプレビューで行ってください。
