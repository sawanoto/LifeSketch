# LifeSketch 023 · 急ぐ車

作品一覧 `works.js` → `023_hurrying-cars/`。タップ・クリック・スペースキーで上の車が加速。最初の操作で同時に出発し、操作しなくても以後は巡航します。「もう一度」で同じ信号位相から再開。「音 ON」で操作を契機にp5.soundのエンジン音を開始します。画面に教訓や結果の評価は表示しません。

## 構成

- `simulation.js`: DOMやp5に依存しない共通走行計算。作品と検証で同一コードを使用。
- `sketch.js`: p5の描画・Pointer Events・音・結果表示。
- `index.html`, `style.css`: 画面・スマートフォン対応。
- `verify.cjs`: `node 023_hurrying-cars/verify.cjs` で操作別走行と不変条件を検証。

ローカルp5.js / p5.soundの同版ペアと `../shared/marpan-25d.js` を使用。リポジトリ全体をHTTP配信してください。

## 調整値

すべて `simulation.js` の `CONFIG` に集約。距離m・時間sの便宜的な世界。燃料は100を満タンとする相対量で、実車のリットル換算ではありません。

| 項目 | 設定 |
|---|---|
| 道路・停止線 | ゴール720m、停止線200 / 400 / 600m（車の位置は前端） |
| 信号 | 全24秒周期、青8・黄2・赤14秒 |
| 位相 | `(経過秒 + 位相) % 24`、位相2 / 4 / 6秒 |
| 青開始 | 第1:22秒、第2:20秒・44秒、第3:18秒・42秒・66秒、以後24秒ごと |
| 巡航・最高速度 | 両車12m/s（43.2km/h）、上のみ最高26m/s（93.6km/h） |
| 加減速 | 最大加速4m/s²、制動6m/s²、目標速度へ比例追従 |
| タップ | スロットル+0.19、毎秒0.8減衰、最大1。35ms未満の重複を棄却 |
| タンク | 両車100 |

信号は共通の経過時間だけで決まり、接近検知・到着時刻・燃料に応じた補正はありません。黄に初めて接したとき、停止距離 `v²/(2×6) + 0.35v` 内なら通過を決断し、それ以外は制動。赤の停止線は越えません。赤・黄の停止目標速度は `sqrt(2×6×残距離)`。青で自然に再加速します。

燃料の毎秒消費は両車共通:

`0.07 + 0.007v + 0.000015v³ + 0.008 × max(a,0) × v`

受け付けた上側のタップ1回につき、走行中0.025、信号停止中0.12を追加消費。停止中はスロットルを速度に反映せず、振動と音だけに反映。燃料ゼロでその場に停止し、下の車は継続します。到着後は燃料計算と入力を停止。

120Hz固定ステップ、実時間差を蓄積して更新。タップ直前にも経過分を更新。表示落ちによる過大な一括更新を避け、1描画あたり最大0.25秒、非表示中は休止。したがってタブを隠した時間は走行時間に含めません。2台・信号・結果は同じシミュレーション時計に従います。描画は共通の世界→画面変換で、車間が広い場合は両車が見えるよう表示範囲が広がります。

## 代表的な計算結果

最初から規則的に入力した検証（端数は丸め）。すべて下側は77.55秒、消費14.23。停止線3か所で比較車が追いつきます。入力で最後の区間の差が残り、同着補正はありません。

| 操作（毎秒） | 上の到着 | 上の消費 | 下との差（時間 / 燃料） |
|---|---:|---:|---:|
| 入力なし | 77.55秒 | 14.23 | 0秒 / 0 |
| 1回 | 77.34秒 | 19.46 | 0.21秒速い / +5.23 |
| 6回 | 73.95秒 | 54.52 | 3.60秒速い / +40.29 |
| 12回 | 73.92秒 | 83.32 | 3.63秒速い / +69.09 |
| 28回を継続 | 到着不能 | 100.00 | — / +85.77 |
| 最初の8秒だけ6回 | 77.55秒 | 18.16 | 0秒 / +3.93 |

`verify.cjs` は、再現性、赤停止線、黄色の停止・通過判断、停止中の空ぶかし、燃料ゼロ、30/60/120Hzの一致、下側条件の一定性を検証します。
