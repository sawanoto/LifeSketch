# 縄文の部屋 / Jomon Room

修正仕様に基づく独立したp5.js / p5.sound作品。LifeSketch第2作品。LifeSketchの静的ディレクトリ構成・GitHub Pages公開方式に従う。既存作品・sharedのソースは変更しない。

## 実装方針

- 家具・家電・布・装飾・生活道具の区分は音色だけに使用。28点すべてが自由な順で消去可能。必需品判定はない。
- 透明度を500msで減らし、影も一緒に消す。他の物は移動しない。
- 土偶は中央の固定位置に描く。遮光器土偶を参考にした輪郭・文様に、`../shared/marpan-25d.js` の `drawEyes()` を直接利用。3眼の形・配置・瞬き計算を共有する。
- 土偶のタップは1100msの瞬きと低い打音。最後のフェード完了時は1300msの瞬きを一度だけ行う。自動瞬きは無効。
- 最終状態は建築（壁・床・窓）と土偶のみ。評価・得点・完了表示・画面遷移はない。
- p5.soundで電子音、木の打音、金属倍音、布のノイズ、澄んだ装飾音を合成。残存物の透明度の合計から人工音を弱め、風と間欠的な鳥声へ移行する。音楽なし。最終状態の人工音の目標振幅は0。
- 音は「音 オフ」ボタンで有効にする。ブラウザーの音声開始制約に対応。非表示タブでは環境音を抑える。
- PC/スマートフォン共通のPointer Events。タッチ対象を最低44 CSS px相当まで補助し、重なる場合は直接ヒットを優先。キーボード用の物ボタンも用意。

## 確認・公開

リポジトリのルートで `python -m http.server 8000` を実行し、
`http://localhost:8000/002_jomon-room/` を開く。
共通描画への相対参照があるため、このディレクトリだけを切り離さない。
p5.js / p5.soundは既存101作品と同じローカル配布版を使用し、CDNに依存しない。
LifeSketchギャラリー `works.js` に2番として追加。GitHub Pagesへの反映は通常のリポジトリ公開手順に従う。

## Kindle用PNG

画面端の「PNG 書き出し」を開き、4段階をそれぞれ保存する。各画像は3200×2400px、UIを含まない。段階は28点・19点・8点・0点と土偶。最終ページに生活道具は残さない。書き出しは現在の消去状態を変更せず、画像中の目は開いた状態に固定する。各ボタンで個別に保存するため、ブラウザーの複数自動ダウンロード制限を避けられる。Kindleのレイアウト・入稿用パッケージ化は別工程。

## 検証

Chromium / PlaywrightでPC幅1100px・スマートフォン幅390pxのタップ、フェード途中と完了、土偶の瞬き、最終状態の一度限りの瞬き、リセット、4段階のダウンロードと状態保持、音声コンテキスト起動、JavaScriptエラーの不在を確認。実機の音量・音色は端末での視聴調整を推奨。
