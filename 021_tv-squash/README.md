# 022 テレビスカッシュ

ルートをHTTP配信し、`021_tv-squash/` を開く。クリック・タップごとに1球を発射する。音声なし。共通 `../shared/marpan-25d.js` をそのまま利用する。

## 調整

`sketch.js` 冒頭の `TV_OUT_REFLECTION`、`RIGHT_RETURN`、`TV_BACK_REFLECTION` が各接点での成功率。初期値の積は20%。最初に発射した球だけ全判定を通過する。`LEG_SECONDS` は各区間の所要秒数。

各球は同じオブジェクトのまま左→テレビ→右→テレビ→左へ進む。接点でのみ確率判定し、消えた球は配列から除去する。球数・入力間隔の制限はない。サイズ変更では区間と進捗を保持して経路を再配置する。非表示タブからの復帰時は経過時間をリセットする。

## 確認

```sh
node 021_tv-squash/tests/behavior.cjs
python -m http.server 8000
# 別ターミナル（Playwrightが必要）
CHROMIUM_PATH=/usr/bin/chromium node 021_tv-squash/tests/browser.cjs
```

- 最初の球の全反射・返球成功、左で終了、全3種類の途中消滅を確認。
- 固定シード10万球で19,993球が帰還（19.993%）。
- Chromiumで1280×900のクリック、390×844のタッチを確認。10回の入力で10球が同時に存在し、最初の球だけが保証対象。
- 同じ球の反射、接点の連続性、テレビでの反射角、右マーパンの無反応を確認。
- 320×568、844×390へのサイズ変更でも対象が画面内に収まり、横スクロールなし。
- ギャラリーから作品へのリンク、PC・モバイル表示、JavaScriptエラーなしを確認。

スマートフォンはブラウザーのタッチエミュレーションで確認。実機確認はPRプレビューで行う。
