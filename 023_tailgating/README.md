# LifeSketch 023 · あおり運転

青い車を一度クリック・タップする。以後は自動進行。キーボードでは青い車のボタンへTabで移動し、Enter / Space。「リセット」で走行中・終了後とも最初から再試行できます。音・教訓・結果表示はありません。

## 実装と調整

- `traffic.js` の `CONFIG` に車両数、車長、初期車間、速度、加減速度、反応時間、発進待ち、静止保持時間を集約。距離はm、時間は秒です。
- 遅延した車間から目標速度を求める簡略車両追従モデル。初期車間で目標速度と走行速度が一致します。操作車だけ1.8秒間加速し、縮んだ車間への反応で減速します。後続の反応遅れが減速を増幅します。車両別の停止時刻を指定する演出ではありません。
- 停止後は10秒の発進待ちを置き、後方に十分な停止列を作ります。これは鑑賞用に増幅したパラメータであり、実際の交通予測には使えません。
- 直前車との安全距離と制動可能速度を即時制限し、重なりを防ぎます。画面外も96台すべて計算します。
- `sketch.js` の `VIEW` が描画倍率とカメラ・終結条件。小画面も車を約48pxで描き、前車を視認できる位置に操作車を置きます。車の倍率は進行中に変えません。
- カメラは最初に操作車を追い、5秒後から実際に速度低下した車列の後端を滑らかに追います。路肩の目地は道路の座標に固定されています。
- 約25秒後、連続9台以上の自然な停止列を検出したら、その車列を最終静止画として保持します。3.5秒かけてカメラを落ち着かせ、requestAnimationFrameを停止。自動リセットしません。
- 描画はrequestAnimationFrame、物理は1/120秒の固定刻み。非表示タブでは休止し、復帰時の時間飛びを防ぎます。外部ライブラリや通信は不要です。マーパンを描かないため共通レンダラーの変更・複製はありません。

## 確認

リポジトリルートをHTTP配信し、`023_tailgating/` を開きます。

```sh
python3 -m http.server 8000
node --test 023_tailgating/tests/traffic.test.cjs
```

数値テストは30秒間の初期等速・等間隔、単発操作、控えめな最高速度、順番に遅れる減速、全車の非衝突、連続停止列、操作車の速度回復を検証します。

Chromium / Playwrightで1280×900と390×844を確認。ギャラリーからの遷移、クリック・タッチによる単発開始、終了後の静止維持、リセット、844×390へのリサイズ、JavaScriptエラーなしを検証。スマートフォン実機・Safariは未確認です。
