# LifeSketch 011 · 怒りの炎

リポジトリルートをHTTPで配信し、`011_anger-flame/` を開きます。既存のローカルp5.js / p5.soundと `../shared/marpan-25d.js` を使用します。ビルド・追加依存はありません。

周囲の7語をクリック・タップすると、0.66秒で身体に吸い込まれ、炎の熱量が増えます。各語は1.15秒休んでから同じ場所の周辺に再出現します。別の語は移動中にも操作でき、タッチ・ペンは接触時、マウス・キーボードはclickで受け付けます。同じ語の移動中の再投入は受け付けません。TabとEnter / Spaceでも操作できます。

熱量は0〜1の連続値。投入ごとに0.18増え、毎秒 `0.018 + heat × 0.025` ずつ減衰します。描画値は指数補間し、着火時の短い増幅を別に管理します。上限から放置した場合、約35秒で基底状態に戻ります。基底の炎は熱量0でも描き続けます。低・中・高の表情は、炎の高さ・幅・揺れ、身体の色、小さな身体の震えとして滑らかに変化します。背景タブから復帰した際も経過時間を減衰に反映します。

身体の輪郭・クリップ・三つ目・怒り顔は共通描画を使用し、共通ファイルを変更していません。炎は身体の輪郭でクリップし、白い目を最後に描きます。7語は別々の楕円上の領域をゆっくり漂います。モバイルでは身体と文字の配置が画面サイズに追従します。動きを減らす設定では文字の漂い・身体の震えを止め、炎の揺れを緩やかにします。

音は最初の操作で `userStartAudio()` を実行し、p5.soundのAudioContextで生成します。吸い込み音、重ねられる短い燃焼音、熱量に連動する低い燃焼音を使用。コンプレッサーで連続投入時の音量を抑え、基底状態は無音になります。右上の音ボタンで消音できます。非表示の間も消音します。鎮火・瞑想・リセット操作はありません。

右下の「静止画を書き出す」から、小さな熾火・投入中・大きな炎をそれぞれ3200×2400px PNGで保存できます。各場面は固定の時刻と強度で再描画し、作品名や操作UIを含めません。実際の熱量・文字の状態は変更せず、保存後は表示サイズに戻ります。既存作品と同様にブラウザのダウンロードを使います。

## 確認方法

```sh
python -m http.server 8000 --bind 0.0.0.0
```

PC・スマートフォンで7語の投入、複数の連続投入、放置による熾火への復帰、音の開始・消音、各PNG保存を確認してください。実機の音色と音量はPRプレビューでも確認してください。

公開は既存のPRプレビュー方式です。作業ブランチからPRを作り、コメントに記載された専用URLと `preview-info.json` のSHAを確認します。所有者の確認後にmainへマージすると、既存の本番公開方法で配信されます。詳細は `../docs/pr-previews.md`。
