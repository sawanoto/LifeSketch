# LifeSketch 023 · 売り手と買い手

あづま手しごと市で見つけた、売り手と買い手の異なる時間。

陶器・編み物・木工・アクセサリーのお店が並ぶ。枠のあるお店をクリック・タップすると商品が手元に届き、買い手は次のお店へ歩く。売り手はその場にとどまり、商品を補充する。視点は買い手を追い、店舗は何度でも続く。回数・所持金・終了画面はない。

- マウス・タッチ、お店のボタンへの Tab → Enter / Space に対応。
- 「はじめから」で購入中・移動中も初期状態に戻せる。
- 音声なし。共通 `../shared/marpan-25d.js` と既存のローカルp5.jsを使用。
- 可視範囲の店舗だけを描画し、店舗・商品・購入履歴の配列を増やさない。
- 画面幅に応じて表示範囲を調整。縦向きのスマートフォンでも横並びの市場を表示する。
- 動きを減らす設定では歩行時の上下動を止める。

リポジトリのルートをHTTP配信し、`023_sellers-and-buyers/` を開く。
