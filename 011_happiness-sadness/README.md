# LIFESketch 012 — Happiness / Sadness

共通の三つ目マーパンが、Happinessで浮かび、Sadnessで沈む。操作をやめると静かに中央へ戻る作品。画面には思想の説明や成功・失敗の表示を置きません。

## 操作

- クリック／タップ：一回の移動。最大変位は体高の約半分、約2秒で中央へ戻ります。
- 連打／長押し：同方向を保ちます。上下の上限は体高の0.8倍。直近の入力が優先されます。
- フォーカスしたボタンはSpace／Enterでも長押しできます。
- 音 ON/OFF：最初の操作から音声を開始。高音・低音は短いサイン波で、発音間隔と音量を制限します。中央では無音です。
- 静止画を書き出す：現在の位置と背景を3200×2400 PNGで保存。UIは画像に含めません。

## 実装・確認

リポジトリルートをHTTP配信し、このフォルダーを開きます。既存のローカルp5.jsと対応p5.sound、`../shared/marpan-25d.js`を参照します。共通描画は変更していません。

`motion.js`は体高単位の臨界減衰モデル。短い入力目標を再設定し、位置・速度は引き継ぐため連打・反転が連続します。入力が途絶えると目標は0へ戻り、正確な時間積分でフレームレートに依存せず収束します。背景は入力とは独立した経過時間で右から左へ26px/秒で光の粒が流れます。中央の水平線が自然な高さを示し、マーパンは共通描画のyawで右向きにして、初版の78%の大きさで表示します。タブ非表示・ウィンドウのフォーカス喪失で長押しを解除します。

`node 011_happiness-sadness/motion.test.cjs`で単発、上限、維持、反転、復帰、長い中断を30/60/120fps相当で検証できます。Chromiumの1440×900と390×844（タッチ）でギャラリーからの遷移、上下操作、長押しと復帰、音声起動、PNGダウンロードを確認。実機での音色・音量確認は別途必要です。

作品番号はmainに先行追加された「怒りの炎」との重複を避け012。既存プレビューのURLを維持するためフォルダー名は011_happiness-sadnessのままです。
