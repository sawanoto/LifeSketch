# LifeSketch 023 · 売り手と買い手 / Sellers and Buyers

あづま手しごと市で見つけた、売り手と買い手の異なる時間。

買い手は右へ歩き続ける。画面をクリック・タップするたび、その瞬間に真上にあるお店から商品がバスケットへ飛び込む。連続タップでも歩行は止まらず、複数の商品を同時に受け取れる。売り手は同じ場所で商売を続け、店舗は何度でも循環する。

- タッチ・マウス、購入ボタンへの Tab → Enter / Space に対応。
- English / 日本語でタイトル・商品名・操作案内・アクセシビリティ用ラベルを切り替え。選択を端末に保存する。
- 「はじめから / Restart」で歩行位置とバスケットをリセット。
- 回数・所持金・終了画面・音声なし。共通マーパンと既存のローカルp5.jsを使用。
- 可視店舗のみ描画。飛行中は最大64点、バスケット内の見える品物は最新9点に限定し、履歴を蓄積しない。
- スマートフォンの縦横表示、動きを減らす設定（歩行の上下動を省略）に対応。

リポジトリのルートをHTTP配信し、`023_sellers-and-buyers/` を開く。
