# No.008 仏の顔も三度まで

立方体をクリック／タップすると、右側面が正面へ90度回転する。Enter／Spaceでも操作できる。画面には説明や操作ボタンを置かない。

- 側面はA・B・Cが普通、Dが怒り。上面は普通、底面は怒り。
- 共通 `Marpan25D` で普通・既存のangry表情を描画し、6面のテクスチャに使用。口は追加しない。
- 固定の視点とY軸回転を分離。回転中は入力を破棄し、完了した3・7・11…回目だけ低音と25msの振動を発生させる（対応端末）。
- 同梱p5.js／p5.soundを読み込み、操作時に音声を開始。音源はWeb Audioで合成。
- 動きを減らす設定では回転時間を短縮し、震えを省略。

リポジトリルートからHTTPで配信する。スマートフォン実機の音量・振動は端末上で確認する。
