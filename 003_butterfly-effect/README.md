# LIFE Sketch No.003 — Butterfly Effect

画面をタップ・クリックすると共通マーパンが羽ばたきます。キーボードでは作品画面にフォーカスしてスペース／Enter。音は最初の操作から開始し、右上で切り替えられます。リセットはなく、風は自然に消えます。

## 風と音

各羽ばたきが独立した風のパケットを作ります。約6.5秒かけて中央から外周へ進み、到着する角度が近い風が合流します。タップ間隔が位相と強さを変え、既存の渦の位置・減衰状態との相互作用で最終形が変わります。1回でも遠くまで届き小さな渦を作り、重なると大きな竜巻になります。粒子パケットは最大28、竜巻は最大4。フレーム時間に基づく更新と描画密度上限2で負荷を制限しています。

同じバージョンのp5.js／p5.soundを002から参照し、Web Audioでノイズを生成。短い帯域ノイズが羽音、ローパスノイズが風音です。全竜巻の合計でゲインを制限し、コンプレッサーを通します。タブが隠れると消音します。外部音声ファイルは不要です。

## 絵本用PNG

右下の「PNG 書き出し」を開き、4場面を個別に保存します。既存002のキャンバス拡大・saveCanvas方式に合わせた3200×2400px PNGです。場面ごとに固定した構図で、文字や操作ボタンを含みません。現在の風の状態を変更せず、保存後は元の画面サイズに戻ります。スマートフォンではブラウザーの画像保存・共有メニューを使う場合があります。

## 検証

リポジトリルートをHTTP配信。Chromiumで1280×900／390×844、初回クリックのAudioContext開始、風の成長・減衰、4つのPNGダウンロード、サイズ復帰、ギャラリー登録、JavaScriptエラーなしを確認。実機のタッチ・音色の最終確認はPRプレビューで行ってください。
