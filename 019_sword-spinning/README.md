# LifeSketch 019 · 剣を振り回すマーパン

画面をクリック・タップすると、もう一体がその位置へ滑らかに移動します。剣に触れると移動を止め、0.24秒で消え、接触から0.95秒後に安全な初期位置へ新しいマーパンが現れます。端への指定は体が収まる範囲に調整します。入力しなければ安全な位置に留まります。

中央のマーパンは共通 `../shared/marpan-25d.js` の通常表情。2体は同じ大きさ・色・表情です。中央の位置・表情・2.5秒周期の回転は接触処理から変更しません。音・カウンター・停止操作・説明表示はありません。

描画と当たり判定で同じ剣ポリゴンを使用し、共通マーパンの通常輪郭のベジェ曲線を各24分割した輪郭との交差・内包を調べます。円形の危険エリアではありません。移動と回転の合計変位が0.5 CSS px以下になる時間刻み（最大1/240秒）で更新します。非表示タブの経過は再生せず、復帰時も連続した状態から再開します。

リポジトリルートをHTTP配信して `019_sword-spinning/` を開きます。検証: `node --test 019_sword-spinning/tests/*.test.cjs`。
