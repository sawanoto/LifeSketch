# LifeSketch 018 · 感情の雪だるま / Emotional Snowball

笑顔・無表情・泣き顔の3体を自由に転がす、無音のp5.js作品。思想の説明、評価、得点、演出効果は表示しません。

## 操作

- マウスまたはタッチでつかみ、上下左右・斜めへドラッグ。押した位置と中心のずれを保ち、手を離した場所で停止します。
- 可視部分の最前面の1体を選択し、その1体を最前面に移します。重なりや完全な遮蔽を許し、ほかの2体の状態は保持します。
- 完全に隠れた場合は前面の個体を動かすか「リセット」。リセットは3体の配置・大きさ・角度を初期化します。

## 実装

- `motion.js`: 中心の実移動距離を操作領域の短辺で正規化して累積。20短辺分で最大幅（操作領域の横幅と高さ÷0.68の大きい方の105%）へ線形成長。共通の縦横比でも領域いっぱいまで大きくなります。初期直径は横幅21%・高さ24%・148pxの最小値。時間や描画フレームを使用しません。
- 回転角は `ds / r`。成長中の半径変化を積分し、上限をまたぐ移動も分割計算。右は時計回り、左は反時計回り。斜めは水平の符号、純粋な縦移動は下が時計回り・上が反時計回り。タップや停止中は変化しません。上限到達後も回転・移動を継続します。
- `sketch.js`: Pointer Events・pointer capture・coalesced samples。単一ポインターだけを受け付け、キャンセル・フォーカス喪失・画面サイズ変更でドラッグを終了。`touch-action:none` はキャンバス内だけに適用します。
- 共通 `../shared/marpan-25d.js` の本体・三つ目・笑顔・泣き顔・クリップを利用。本体の縦横比（高さ＝幅の0.68倍）と三つ目の配置・表情は共通描画のまま使用し、泣き顔の涙だけを描き足します。口は追加しません。全体を同じ座標系で回転・拡大します。共有ファイルは変更しません。
- 当たり判定は回転・拡大を逆変換し、共通本体のパスで判定。中心はキャンバス内に制限します。画面変更時は中心の相対位置、距離、角度を維持し、直径を再計算します。

## 確認

`node --test 016_emotional-snowball/tests/motion.test.cjs`

Chromium / Playwrightでギャラリーと作品を1280×900、390×844で確認。マウスドラッグ、CDPの実タッチイベントによる斜めドラッグ、タップ時の不変、独立した成長、停止後の状態維持、重なりの前面選択、上限後の移動、リセット、リサイズ・横向き時の中心位置、タッチ時のスクロール抑止、JavaScriptエラーなしを確認。スマートフォン実機・Safariは未確認です。
