# 019 · 何か欲しい

上の物、下の感情をクリック／タップして、中央のマーパンに与える。キーボードはTabで選択し、Enter／Spaceで与える。

## 実装

- 共通 `../shared/marpan-25d.js` と既存ローカルp5.jsを参照。共通描画処理や既存作品は変更しない。
- 物質5種類は線のあるイラスト、感情5種類は淡い抽象図形。操作対象はラベル付きの標準button。
- すべて900msで身体の中心へ移動し、終盤で縮小・消失する。受け取り時に360ms、身体が最大1.2%だけ伸縮する。表情・吹き出しは固定。
- 各選択肢は移動中だけ無効になり、吸収後に同じ場所へ復活。他の選択肢は同時に与えられる。飛行中の要素は終了時に破棄し、累積回数や満足度は保存しない。
- リサイズ時は中央の描画領域と吸収先を追従。低い横画面でも上下の選択肢を維持する。動きを減らす設定では移動を中央でのフェードに置き換える。
- 音声、ゲージ、正解、終了条件、解説メッセージは設けない。

## 検証

システムChromium＋Playwrightで一覧からの遷移、1440×900のマウス操作、390×844・320×568・844×390のタッチ操作を確認。各画面で全10種類と同時入力を合わせ40回与え、吹き出し・通常表情が変わらず、選択肢が復活し、飛行要素が残らないことを検証。移動中の縦横リサイズ、キーボード、動きを減らす設定、JavaScript例外なしも確認。スマートフォンはエミュレーションで、実機確認は未実施。
