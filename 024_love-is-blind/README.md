# 恋は盲目 · LIFESketch 024

恋をすると、世界が狭くなる。世界は何も変わっていないのに。

ドラッグ、広場のタップ、または広場にフォーカスして矢印キーで白いマーパンを移動します。くすんだ桃色の相手に近づくと視野が狭まり、離れると回復します。「はじめから」で位置・時間・視野をリセットできます。音はありません。

既存のローカルp5.jsと `shared/marpan-25d.js` を利用。距離をsmoothstepで視野へ変換し、時間に基づく補間で暗幕を滑らかに変えます。低解像度の補助Canvasに放射グラデーションの穴を描き、通常の描画に重ねています。仕事の書類、家族の洗濯、友人、バス、通行人は視野とは独立した時間で動き続けます。リサイズしても正規化した位置を維持します。新しいライブラリ、音声、ビルド工程は追加していません。

## 検証

ルートを `python -m http.server 8000` で配信し、PlaywrightとChromiumのある環境で `node 024_love-is-blind/tests/browser.cjs` を実行。

PC（1280×900）とモバイル相当（390×844）のギャラリー経由の遷移、ドラッグ／タップ、接近・回復、視野外の時間進行、矢印キー、リセット、320px幅と横向きでの横溢れ、コンソール・HTTPエラーを確認します。実機スマートフォンの最終的な操作感はPRプレビューで確認してください。
