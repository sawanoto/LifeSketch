# LifeSketch 006 · 免罪符と生命保険

左右の書類をクリック・タップ（キーボードではTabとEnter/Space）すると、コイン、書類、薄くなる雲、安心した目が同じ2.6秒のリズムで動きます。左右は独立し、同時操作できます。購入中も連続して押せます。押した回数を左右それぞれで受け付け、受け渡しを順番に続けます。タッチ操作は1タップにつき1回だけ購入します。両側を一度ずつ購入すると「買ったのは、安心。」が6秒かけて現れて消えます。リセットで購入待ちもすべて取り消して再体験できます。

共通の `../shared/marpan-25d.js` を変更せず、同じ寸法・同じ三つ目と `happy` 表情を使用。p5.js / p5.soundは既存の002内の同一バージョンを参照します。最初の操作で `userStartAudio()` を呼び、同じAudioContextで金属音・紙のノイズ・上昇する三音を合成します。音オフは再生中の音にも適用されます。リセットは再生・予約音も止めます。

雲の不透明度は購入ごとに漸減しますが、下限を設けて消しません。過去の出来事や将来の事故・病気を取り除く演出はありません。免罪符販売を通じた安心の追求を描く寓意であり、歴史的制度の厳密な再現ではありません。生命保険は契約条件に応じた経済的保障であり、制度・商品の同一性を主張しません。これらの説明は作品画面へ追加せず、操作を中心にしています。

リポジトリルートをHTTP配信し、`006_peace-of-mind/` を開きます。スマートフォンでも左右分割を維持し、書類は別々のHTMLボタンです。動きを減らす設定では雲の揺れとコインの弧を省きます。公開手順は `../docs/pr-previews.md` に従います。
