# LifeSketch 008 · 選択のパラドックス

赤いジャムを、100種類と6種類の売り場からひとつずつ探す作品。`../shared/marpan-25d.js` を直接参照し、既存作品と同じローカル p5.js / p5.sound を使用します。

- 左右どちらからでも開始できます。最初に瓶を選んだ時点で売り場を確定し、`performance.now()` で計測を開始。その最初の選択も判定に含みます。最初から正解なら0秒になります。
- 不正解は毎回1回として記録。同じ瓶への再タップも数えます。触れた瓶の下に小さな点が残ります。
- 正解で計測を終了し、もう片方の売り場を操作可能にします。両方終了後に秒数と不正解回数を比較表示。時間の補正・順序の強制・正解の誘導はありません。
- 正解の色・瓶の大きさ・ラベル・音・マーパンの喜びは左右同一。各売り場の正解位置は開始・リセット時に独立してランダム化します。100種類側には赤系を含む99色の異なるダミーを配置します。
- モバイルでは左5列、PCでは10列。左右を維持し、画面の幅に応じて共通の瓶サイズを決定。配置変更で探索状態や時間はリセットしません。ページ非表示中も実時間の計測は続きます。
- マウス・タップ・キーボードのTabとEnter/Spaceに対応。音は最初の操作から開始し、音ボタンで切り替えられます。OSの動きを減らす設定では跳ねと揺れを止めます。
- 「もう一度」で記録と位置を初期化。「絵本のための PNG 保存」で現在の配置・選択状態を長辺4000pxのPNGに保存します。両方終了後は結果も収録。操作ボタンは入りません。保存は計測を停止・補正しません。

リポジトリルートで `python -m http.server 8000` を起動し、`/008_paradox-of-choice/` を開きます。外部CDNや追加ビルドは不要です。
