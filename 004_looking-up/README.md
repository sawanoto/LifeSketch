# LifeSketch No.4 · 飛行機を見上げる

空をクリック／タップすると、そのX座標へ飛行機が一定高度で、滑らかに加速・減速しながら移動します。移動中も目的地を変更できます。左右矢印キーは画面端への移動です。

街のマーパンは `../shared/marpan-25d.js` の描画をそのまま使用しています。機体のX座標から85〜190px以内で反応し、三つの瞳の位置を約0.16秒の時定数で補間します。顔は回転させず、口も追加していません。停止中も真下の住民は飛行機を見上げます。

p5.js / p5.soundは既存No.2の同一バージョンを相対参照します。最初の操作で `userStartAudio()` を呼び、控えめな合成エンジン音を開始します。停止時は音を弱め、音ボタンと非表示タブではミュートします。

リポジトリルートをHTTPで配信して `004_looking-up/` を開いてください。

確認済み: Chromiumの1440×900と390×844（タッチエミュレーション）でギャラリー遷移、左右操作、移動途中の反転、停止、高度固定、近傍と範囲外の視線、音声開始・ミュート・再開、リサイズ、矢印キー。実機スマートフォンでの音色・音量の確認は別途必要です。

## 見やすさと動きの調整

飛行機は速度を保ちながら目標へ近づき、発進・停止・折り返しを滑らかにつなぎます。マーパンはPC幅で約1.6倍、390px幅で約2倍に拡大し、配置数と窓の段数を減らしました。共通の三つ目を維持し、見上げ時の瞳の上方向への移動量も少し増やしています。
