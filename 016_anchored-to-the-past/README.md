# 016 · 過去の杭 / Anchored to the Past

画面をクリック／タップすると杭を1本打つ。音声、削除、切断、リセット、説明文は設けない。作品一覧へのリンクのみ表示する。

## 実装

- 共通 `../shared/marpan-25d.js` と既存ローカルp5.jsを参照。中央・右向き・通常表情。杭の数で位置、サイズ、表情を変えない。
- `performance.now()` の経過秒 × 24 CSS pxを累積移動距離とし、全粒子・全杭に共通適用。低FPSやバックグラウンド復帰でも経過時間を切り捨てない。
- 杭は生成時のワールドX座標と正規化Yを保存。画面座標はワールドX−累積距離。粒子だけ剰余で右端へ循環する。
- 各杭に身体の同一点から糸を1本描く。左端を越えた杭はアクティブ配列から除き、正規化Yのみ接続情報として永久保持。左端のその高さまで糸を描き置く。画面外の距離は描画結果に不要なので保持しない。
- 画面外の糸は透明なp5.Graphics（密度1）へ蓄積し、毎フレームは画像1枚を合成。個別の接続情報は削除しない。リサイズ時のみ全接続からレイヤーを再構築。通常フレームの負荷は画面内の杭数に比例し、保持メモリは累積接続数に比例する。
- 入力はcanvasのpointerdownのみ。マウス・タッチ・ペンを統一し、合成クリックによる二重生成を防止。ドラッグでは連続生成しない。
- リサイズ時は画面内の杭の相対位置を保持し、マーパンと描画領域を画面サイズに適合する。時間経過によるサイズ変更はない。

## 検証

システムChromium＋PlaywrightでPC（1440×900）とモバイル（390×844、タッチエミュレーション）の一覧→作品遷移、1操作1本、リサイズ後の接続保持、JS例外なしを確認。1秒24pxの移動と1万本の画面外保持を検証。1万本蓄積後の60回draw平均はPC約0.87ms、モバイル約1.04ms（当該Cloud環境の描画処理時間。実端末のFPS保証ではない）。実機スマートフォンでの確認は未実施。
