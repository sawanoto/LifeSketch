# LifeSketch 005 · マーパンファンデーション

リポジトリのルートをHTTP配信し、`005_marpan-foundation/` を開きます。

- 初期選択はファンデーション。下部のコンパクトで白とピンクを切り替えます。
- 顔をタップ、またはドラッグすると柔らかい円形ブラシで色が残ります。重ねるほど選択した色に近づきます。
- リセットで化粧レイヤーだけを消去します。音ボタンで消音できます。
- PNG保存で現在の顔と背景を3200×2400pxで保存します。操作ボタンや文字は含みません。モバイルブラウザーによっては画像を開いて保存してください。

## 描画と入力

`../shared/marpan-25d.js` の `Marpan25D` を直接使用。`drawBody` → `beginClip` → 化粧 → 輪郭 → `drawEyes` の順に描画します。共通部品は変更・複製していません。三つ目の形、配置、瞳は共通のnormal状態に固定し、自動瞬きや表情変化を行いません。

化粧は1600×1600のオフスクリーンCanvasに半透明の放射グラデーションを蓄積。1000単位の顔座標へ入力を変換し、移動の間を12単位以下で補間します。共通クリップで肌に限定し、目は常に前面に描画します。輪郭の外は表示されません。リサイズで化粧Canvasを作り直さないため状態を保持します。書き出しも同じ描画処理を使用します。既存作品の書き出しは作品固有のため流用せず、共通描画のみ再利用しています。

Pointer Events、pointer capture、coalesced events、`touch-action:none` を使用。ドラッグ中のスクロールと操作ボタンへの入力混入を防ぎます。ResizeObserverでコンテナ寸法を追従します。画面の拡大率・ピクセル密度も入力座標へ反映します。

既存のローカルp5.js / p5.soundの組を読み込み、ユーザー操作で `userStartAudio()` を呼び出します。Web Audioのノイズ・フィルター・音量包絡で選択音と2種類の塗布音を生成し、塗布音は150ms以上の間隔を空けます。音源ファイル・音楽はありません。

## 動作確認

Chromiumの1100×900（deviceScaleFactor 2）と390×844で確認。マウスのタップ・ドラッグ、2色の蓄積、リサイズ前後の化粧ピクセル一致、リセット後の透明化、PNGダウンロード、ギャラリー登録、タッチエミュレーション、AudioContextのrunning状態を確認。実行エラーなし。スマートフォン実機の音色・触感は未確認です。
